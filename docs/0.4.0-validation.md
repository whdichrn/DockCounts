## 材质行为

背景强度只作用于背景，数字不随背景一起变淡。关闭高光会使用哑光磨砂，因为公开原生玻璃没有单独关闭全部折射亮边的接口。描边选项控制附加描边。鲜明显示增强文字、描边与有色染色的对比；自动数字颜色根据实际背景和染色选择深浅，也可手动指定。

macOS 26+ 使用原生玻璃；macOS 15 使用 `NSVisualEffectView` 磨砂兼容路径。材质支持与高光回退、染色和文字对比已有基础测试；当前实机无法代替 macOS 15 上的材质视觉验收。原有 Dock / Space 跟踪逻辑延续 0.3，不将本轮设置验收表述为全部桌面手势的认证。

## 检查结果与范围

- `swift test`：41 项中 36 项通过、5 项依赖桌面的测试显式跳过，零失败。包含各功能组合、单窗口点击放行/接管、偏好迁移与损坏回退、全部配置持久化、材质选择、颜色代码、文字对比、系统登录项成功/失败/等待允许的状态。
- `scripts/test-live.sh`：真实窗口清单与最小化窗口恢复通过。
- `DOCKCOUNTS_TEST_MENU=1 scripts/test-live.sh`：真实 AX 清单、实际 SwiftUI 菜单按钮内容、窗口恢复通过。
- 单窗口对照：临时 fixture 使用 `--single-window`，同一份源码的 debug 包使用 `--smoke-menu` 触发生产回调，随后实际点击窗口行。
- 通用 release 包含 arm64 / x86_64；两者 `minos 15.0`；严格签名检查通过。调试菜单驱动不编入 release 包。

进程内 smoke 驱动不向桌面发送合成鼠标事件。本轮远程窗口控制无法可靠触发物理 Dock / Space 手势，因此不声称实测了所有物理点击与桌面动画组合。该边界及 0.3 的既有过渡测试见 [0.3 验证记录](0.3.0-validation.md)。
