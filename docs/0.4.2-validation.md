# 0.4.2 图标、后景预览与设置窗口

日期：2026-11-21；Apple Silicon，macOS 27.2.1。

- 应用图标以已选定的衬线 DC 字形重做，较小的 C 位于右下方交错。青蓝、紫色与珊瑚色后景保留冷暖变化，字形使用浅色和轻微阴影。SVG 为编辑源，PNG 和多尺寸 ICNS 由现有脚本生成。
- 设置窗口采用固定大小，只保留关闭能力；禁用最小化、缩放和全屏。安装版的辅助功能树显示缩放按钮禁用；Window 菜单中的 Minimize、Minimize All、Zoom、Zoom All、Fill、Full Screen Tile 均禁用。
- 角标预览提供多彩、明亮、深色三档后景，已在安装版实际切换并截图。后景只作用于预览，不更改桌面、Dock 或实际角标的配置。
- 预览中的兼容磨砂使用窗口内部采样，以便反映预览后景；实际 Dock 面板继续采样窗口背后的桌面。预览数字适度放大，位置按图标右下角调整。
- 安装版显示 0.4.2，辅助功能授权和原有配置保持；本机开机启动仍为用户此前开启的状态。本轮没有还原或改写角标材质参数。
- 本机 `swift test`：36 项基础测试通过，5 项依赖桌面的测试显式跳过，零失败；通用 release 构建和严格签名检查通过。

真实截图见 [三种预览后景](manual/screenshots/23-preview-backdrops.png)，详细使用说明见 [实机图解](manual/README.md)。背景对照使用同一组材质参数，仅切换预览后景。

本轮改动没有重做 Dock 跟踪与窗口选择逻辑；既有桌面过渡覆盖边界见 [0.3 验证记录](0.3.0-validation.md)，功能开关、材质和登录项验证见 [0.4 验证记录](0.4.0-validation.md)。
