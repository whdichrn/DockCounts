# DockCounts 0.3.0：改动与验证

日期：2026-11-21。Apple Silicon，macOS 27.2.1，Xcode 27.2。此记录区分安装版验收、调试入口回归和未覆盖的交互，避免将程序内调用视为物理鼠标或手势实测。

## 图标

新增可编辑的 [App 图标 SVG](../Artwork/AppIcon.svg) 与 [菜单栏 SVG](../Artwork/MenuBarTemplate.svg)。蓝灰底、错落窗口与 Dock 托盘构成统一轮廓；菜单栏使用独立单色模板。生成 16–1024 px 的多尺寸 ICNS、PNG 和矢量 PDF，设置页、菜单栏和应用包均已接入。生成工具为 `scripts/generate-icons.sh`，需要 macOS 的 iconutil 和 librsvg。

## 减弱透明效果

当前系统上比较了 HUD、popover、menu、SwiftUI regular material，以及原生玻璃 regular/clear。开启减弱透明效果时，前几种背景明显变实；clear 保留可见模糊，但未经调色时数字对比度不足。因此 macOS 26+ 在该选项开启时使用 clear 玻璃加 55% 的系统窗口背景色遮蔽；关闭时使用 regular 玻璃。颜色随深浅色外观变化，数字、细边框仍响应辅助显示设置。

[实机材质对照](manual/screenshots/08-material-reduced.png)：左上为选定配方，中上为未调色的 clear，右上为 SwiftUI regular，下排为 AppKit 对照。样本使用彩色棋盘背景，没有重绘系统材质。已实际切换深色/浅色及减弱透明效果开关；结束后恢复原来的浅色、减弱透明效果开启状态。

macOS 15 保留 NSVisualEffectView 兼容路径，其减弱透明效果表现受旧系统的材质策略约束。本机结果不能等同于旧系统保留相同模糊。

## Dock 跟踪与显隐

- 高层级角标面板明确采用 stationary，避免继承临时面板在 Mission Control 中的默认隐藏行为。
- 隐藏用 orderOut，显示前先设置坐标；仅在应用退出或 Dock 进程更换时回收面板。
- 命中失败与确认离屏分开；短暂未知最多保留 140 ms，确认离屏立即隐藏。多个位置参与可见性探测，兼容 Dock 在窗口总览中返回容器节点。
- 窗口读取失败最多保留 2 秒的有效结果，真实零窗口立即生效。
- 每约 100 ms 检查 Dock 边界及首、中、末几何锚点；边界未变但内部图标移动也会触发刷新。指针靠近、几何变化和桌面通知触发约 30 Hz 的短时跟踪。
- 系统事件以公开 NSWorkspace 通知和 Dock 支持的 AX 通知为提示；不依赖未公开的 Mission Control 状态通知。
- 运行应用清单按启动/退出事件和低频校验更新，避免在跟踪循环中反复同步查询 Launch Services。
- 面板采用系统可表示的整数点坐标和尺寸，消除半点请求被系统取整后不断重复 setFrame 的问题。

已通过系统设置真实切换 Dock 自动隐藏并恢复。采样记录确认角标跟随离屏/重显，10 个面板在这一过程中复用。[最终安装版采样摘要](0.3.0-transition-summary.json)包含样本数与复用断言。原始诊断记录仅保留在本机临时目录，仓库不包含业务窗口内容。

## 自动化与窗口流程

23 项基础测试通过，普通 swift test 显式跳过 5 项需要桌面状态的验收项。新增测试覆盖短暂未知/持续未知、确认隐藏、远距离指针下的移动跟踪与恢复降频、未知窗口清单/真实零窗口及过期数据。

真实三窗口 fixture 验证总数 3、最小化数 1、Dock 映射和已安装角标；恢复后验证总数仍为 3、最小化数为 0。菜单内容和窗口选择另用同源码调试包的 `--smoke-menu` 入口打开生产菜单，随后通过实际界面按钮选择 Beta，确认恢复、主窗口、焦点和前台应用状态。该入口不编入 release。

当前远程控制通过共享窗口转发输入，不能可靠等同于物理鼠标点击 Dock 或触发系统全局手势。此次没有将这些操作报告为完整通过。全部 Mission Control、显示所有窗口、显示桌面、切换桌面的手势与动画组合，以及实体多屏，仍未逐项实机覆盖；相关修正已有代码和模型测试，需继续观察真实交互。

## 重现

```sh
swift test
scripts/test-live.sh
DOCKCOUNTS_TEST_MENU=1 scripts/test-live.sh
DOCKCOUNTS_UNIVERSAL=1 scripts/build-app.sh
```

菜单集成测试前应退出已有 DockCounts 和其他 fixture。调试包通过进程内内存事件调用生产处理器，不向桌面注入鼠标事件。

可选的只读跟踪记录器：

```sh
swift scripts/fixtures/ObserveDock.swift 60 /tmp/dockcounts-transitions.jsonl
```

记录 Dock/角标边界、角标窗口编号和可见性；不采集屏幕像素、窗口业务标题或键盘输入。生产诊断日志仅在进程环境显式设置 `DOCKCOUNTS_DIAGNOSTICS=1` 时开启。最终安装实例按普通方式启动。
